## 7. 分享前要做的检查

| 项 | 状态 | 说明 |
|---|---|---|
| 单文件、免安装 | ✅ | `dist/DNSGuard-v0.4.8-win64.zip`：exe + 使用说明 + LICENSE |
| 首次运行提示 | ✅ | 一次性「使用须知」，同意后才进界面 |
| 无数据外传 | ✅ | 全部本机完成，不上报 |
| 写操作可回滚 | ✅ | 改 DNS 前自动备份 |
| 只读目录可用 | ✅ | 报告/备份目录写不进去时自动落到 `%LOCALAPPDATA%\DNSGuard` |
| 无 WebView2 时 | ✅ | 自动退到 Edge `--app` 窗口 |
| **代码签名** | ❌ | 没买证书，SmartScreen 会提示"未知发布者"，用户需点「仍要运行」 |
| **杀软误报** | ⚠️ | PyInstaller 单文件常被启发式误报，建议自己先传 VirusTotal 看一眼 |
| **干净机器实测** | ❌ | 只在开发机验证过；建议在一台没装 Python 的 Win10/11 上跑一遍 |

另外两条不是技术问题：

- **别宣传"翻墙/突破封锁"**。这个工具只做劫持检测和 DoH 配置，一旦往那个方向讲，性质就变了。
- **公开分发建议开源**。16 MB 的闭源 exe 改系统 DNS，很难让人放心；源码 + 可复现构建反而更容易被接受。

## 11. 开源协议

[MIT](../LICENSE) © 2026 parkerli

可以自由使用、修改、分发、商用，保留版权声明即可。没有附加条款，也不要求在 UI 里署名。

**为什么是 MIT**：这是工具，不是框架，约束越少越容易被拿去用。你 fork 之后做了改进，
欢迎提 PR，但不必——直接改自己那份也完全合法。

**关于信任**：DNS Guard 要读系统 DNS 配置、写 DoH 注册表、部分操作需要管理员权限。
这类工具闭源就没有可信度可言，所以源码完整放在仓库里，打包脚本也一并公开。
你可以自己跑 `python build.py` 出一份 exe，和 Release 里的产物对比。
